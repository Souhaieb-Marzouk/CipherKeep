CipherKeep settings

Version 0.1.0 shell. No account, no telemetry, no remote scripts.

Autofill

Autofill runs only after an explicit popup action, on an exact item origin that was enabled in the item editor. It uses activeTab/scripting, never submits a form and holds no broad host permissions.

Recipe registry

The offline registry is signature-verified before use. Hash is SHA-256 of the canonical JSON.


      


      
Sync

      

        
HTTPS only. Tokens are stored in browser.storage.local, which is not an OS keychain; use a revocable, least-privilege token.

        

          
          
          
          
          
          
          
        

        

        

        

      


      
Updates

      

        

          Manual check of GitHub Releases with ETag caching. No identifiers or query parameters are sent.
          Nothing is downloaded or installed by this action.
        

        

          
        

        

        
Download and install arrive in P5-002.

      


      
Storage

      

        

          The vault header/recovery metadata is stored in browser.storage.local; the keyring
          exists only in background memory.
        

        
IndexedDB ciphertext storage remains reserved for item records in P1.
