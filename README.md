# CipherKeep

CipherKeep is a local-first password manager for Android and Firefox.

- No account, subscription, advertising, analytics, telemetry, or CipherKeep server.
- Your vault stays on your devices; network access is limited to user-initiated update checks.
- Open source under the GNU Affero General Public License v3.0.

**Status:** pre-release. There is no public release and no independent security audit yet. Do not use the current code for real credentials.

Security reports: see [SECURITY.md](SECURITY.md).
