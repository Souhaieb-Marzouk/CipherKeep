# CipherKeep 2.2.2

CipherKeep 2.2.2 tightens how items move between devices and cleans up the
Android settings surfaces.

## Bulk selection

- Multi-select now has **Select all** and **None** actions, so every visible item
  can be pinned, moved or deleted in one step. Selection follows the current
  search, folder/tag filter and Favorites filter.
- Pinned items are now selectable too. Previously they were excluded from
  selection even though bulk actions applied to them.

## Import is Android-only

- The Firefox extension no longer offers **Import passwords**, and the
  `import-plaintext` message was removed from its protocol and background
  worker. Plaintext CSV/JSON/ZIP/Proton imports are handled only by the Android
  app, which has the full parser set.
- Firefox keeps its encrypted `.ckexp` backup restore, which is a CipherKeep
  recovery path rather than a third-party import.

## Pairing and sync

- Android can now **join a vault from a pairing code**, pasted or captured from
  a QR code, with a new local master password. This completes the pairing
  matrix:
  - Android phone → Android phone
  - Android phone → Firefox extension
- Joining adopts the paired vault identity, stores the relay endpoint and token,
  clears stale items from the previous local vault, and pulls remote records
  once so the new device starts in sync.
- The pairing card is now labelled **Pair another device** and no longer calls
  the code one-time; it carries the vault key, so it must still be treated as a
  password.

## Android settings cleanup

- Removed from **Advanced settings**:
  - the **Autofill Inspector** block and its recipe-registry panel
  - the **Password health** section
  - the **About** block that printed the stale `CipherKeep 0.1.0-shell` and
    `Rust core connected via UniFFI` text
- The Settings hub keeps its Password health and About entries, which show the
  real version and links.

## Verification

- Kotlin debug compile and the Android unit tests pass.
- Firefox typecheck, esbuild build, 44 Vitest tests, CSP scan and extension lint
  pass with the import path removed.
