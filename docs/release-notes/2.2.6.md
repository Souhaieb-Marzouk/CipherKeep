# CipherKeep 2.2.6

CipherKeep 2.2.6 restores the Android interface icons and fixes the workflow pin
that failed the supply-chain audit.

## Restored icons

- The Android UI symbols (nav glyphs, settings rows, favorites, item-type
  markers, section bullets) were stored as mojibake after an earlier update:
  UTF-8 text had been read with the legacy Windows code page and written back,
  turning `♥`, `★`, `⚙`, `✈`, `✉`, `◷`, `◔`, `◈`, `⌂`, `✎`, `›`, `…` and `·` into
  sequences such as `â™¥`.
- Every affected source file is now clean UTF-8 and the original glyphs are
  restored: navigation, settings, the vault list, item details, the generator,
  dialogs and the import screen.
- The extension's one affected status string (`·`) and the 2.2.4 release notes
  arrow are fixed as well.

## CI supply-chain audit

- `dtolnay/rust-toolchain` was pinned to a commit that does not exist in that
  repository, so zizmor reported `impostor-commit` (high) and
  `ref-version-mismatch`. It is now pinned to the commit of the immutable
  `1.120.0` ref with a matching version comment.
- `actionlint` and `zizmor` (including the online audit set) pass locally.

## Compatibility

- No vault, sync or protocol change. Android 2.2.6 interoperates with Firefox
  2.2.6 and with earlier 2.2.x extensions.
