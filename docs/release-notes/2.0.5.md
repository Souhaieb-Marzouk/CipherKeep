# CipherKeep 2.0.5

CipherKeep 2.0.5 is a new Android app identity and the release that adds
password-manager import, a redesigned Android interface, and dedicated record
types.

## Important Android migration

The original Android signing key was lost. Android cannot update an app across a
signing-key change, so this release uses:

```text
Package: dev.cipherkeep.app.v2
Version: 2.0.5
```

The new app installs **alongside** the old `dev.cipherkeep.app`.

Before removing the old app:

1. open the old app
2. export an encrypted `.ckexp` backup
3. save the backup password and your recovery shares
4. install this new app
5. import the `.ckexp`
6. re-enable Android autofill
7. re-register passkeys
8. re-enter sync, alias and emergency settings
9. verify the items, then remove the old app

Uninstalling the old app without an export deletes its vault.

## Highlights

### Import from other password managers

Android and Firefox support plaintext Proton Pass, Bitwarden, 1Password and
KeePass exports.

Android also supports:

- 1Password `.1pux`
- password-protected Bitwarden JSON using PBKDF2-HMAC-SHA256
- password-protected KeePass `.kdbx`
- Proton Pass PGP-encrypted ZIP exports

Bitwarden Argon2id exports are rejected. Proton PGP and encrypted Bitwarden
imports currently require Android.

## Known limitations

- no independent security audit
- the Android signing identity changed; old app data requires an export/import
- Bitwarden Argon2id encrypted exports are rejected
- Firefox encrypted Bitwarden and KeePass imports are not implemented
- Proton PGP import is Android-only
- imported non-login items may be flattened
- no Firefox browser autofill yet
- Travel Mode is not a forensic control
- some OEM clipboard implementations may not preserve the sensitive marker

## Install

### Android

Download and install the signed APK. Verify its SHA-256 against `checksums.txt`.

### Firefox

Install the AMO-signed XPI.

## Reporting

Use GitHub private vulnerability reporting for security issues. Do not include
real credentials.
