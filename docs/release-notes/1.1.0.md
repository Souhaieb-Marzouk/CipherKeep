# CipherKeep 1.1.0

CipherKeep 1.1.0 is the second official release. It adds password-manager
import, a redesigned Android add flow, dedicated card and identity records, and
a refreshed vault interface.

## Highlights

### Import from other password managers

Android and Firefox can import plaintext exports from:

- Proton Pass CSV
- Bitwarden JSON and CSV
- 1Password CSV
- KeePass CSV
- generic CSV

Android also supports:

- 1Password `.1pux` archives
- password-protected Bitwarden JSON using PBKDF2-HMAC-SHA256
- password-protected KeePass `.kdbx` databases
- Proton Pass ZIP exports containing PGP-encrypted `data.pgp`

Bitwarden Argon2id exports are not supported. Proton PGP and Bitwarden
encrypted imports currently require Android.

### Android design and add flow

- bottom navigation: Vault, Add, Security, Settings
- type-aware Add screen:
  - Login
  - TOTP
  - Note
  - Card
  - Identity
- dedicated card fields:
  - cardholder
  - card number
  - expiry
  - CVV
- dedicated identity fields:
  - full name
  - email
  - phone
  - address
  - company
  - job title
- type-aware vault cards with badges, folder labels and favorites
- redesigned item detail header
- redesigned settings header and cards
- improved empty states
- fixed remaining text-encoding artifacts

### Fixes

- first-run setup no longer switches to the unlock screen after the phone is
  locked and unlocked
- passkey activities are correctly gated at API 34 for lint
- Proton JSON export mapping added
- 1Password `.1pux` and KeePass `.kdbx` import paths added

### New icon

- 2.5D shield/keyhole icon across Android and Firefox

## Verification

- Android unit tests
- Android lint
- Rust core and FFI tests
- Firefox 44 tests and WASM smoke test
- on-device Android import instrumentation:
  - Proton CSV
  - Bitwarden JSON

## Known limitations

- no independent security audit
- Bitwarden Argon2id encrypted exports are rejected
- Firefox encrypted Bitwarden and KeePass imports are not implemented
- Proton PGP import is Android-only
- imported non-login items may be flattened into login/notes
- no Firefox browser autofill yet
- Travel Mode is not a forensic control
- some OEM clipboard implementations may not preserve the sensitive marker

## Install

- Android: install the signed APK from this release.
- Firefox: install the signed XPI from this release; updates are managed by the
  AMO unlisted channel.

## Reporting

Use GitHub private vulnerability reporting for security issues. Do not include
real credentials.
