# CipherKeep 2.3.0

CipherKeep 2.3.0 changes how devices exchange changes, makes deletions stick,
speeds up large vaults and refreshes the interface.

## Explicit sync instead of background sync

- The 15-minute background sync is gone. Nothing is uploaded or downloaded until
  the user asks for it, so local edits and deletions are never overwritten by a
  silent pull.
- **Relay sync** now has two actions:
  - **Upload changes** merges with the relay and then publishes this phone's
    state.
  - **Download changes** merges the relay state into this phone without
    publishing.
- The screen states that nothing syncs on its own, so the sequence is clear:
  upload on the phone that made the change, then download on the other one.

## Deletions propagate

- Deleting an item now writes a CRDT tombstone instead of dropping the row, and
  tombstones participate in every merge. A later download can no longer
  resurrect a record that was deleted on another phone.
- Tombstones are kept locally (hidden from the list) so the deletion keeps
  winning subsequent merges.
- Bulk delete uses one batch and a single list refresh.

## Speed

- Opening the vault no longer re-exports every item on every load. Loading now
  only decrypts the stored records, which removes one expensive operation per
  item and speeds up password and biometric unlock on large vaults considerably.
- Importing hundreds of records no longer refreshes the whole list after each
  record; the list is refreshed once when the import finishes.
- Deleting many records no longer reloads the vault after each deletion.

## Security tab

- New overview card with a security score, a progress bar and compact counters
  for weak, reused, breached and missing-second-factor accounts.
- Protection card shows the auto-lock timeout, biometric state and the fact that
  sync is manual.
- Password health and breach monitoring now sit in their own cards with short
  explanations.

## Icons and logo

- Navigation and settings icons are drawn in Compose as layered “2.5D” icons
  (shadow, gradient plate, highlight and light symbol) instead of text glyphs, so
  they cannot be corrupted by fonts or encoding.
- The login and setup screens show the real CipherKeep launcher icon, centred
  above the title.
- The Advanced settings row uses the new depth icon.

## Compatibility

- Android only; no vault, record or relay protocol change. The signed Firefox
  2.2.4 package remains interoperable.
