# CipherKeep 0.1.3 beta

Pre-release build for testing. Do not use with irreplaceable credentials.

## Highlights

- Local vault with Argon2id and XChaCha20-Poly1305.
- 2-of-3 recovery shares.
- Android biometric unlock and autofill.
- Firefox popup vault.
- Optional encrypted sync through an opaque relay.
- Email aliases, emergency access, Travel Mode, phishing warnings, HIBP prefix
  checks and a local password-health dashboard.
- Family sharing with owner/editor/viewer roles.
- Experimental WebAuthn PRF unlock and Android passkey provider.

## Verification

Download `checksums.txt` and `checksums.txt.minisig`, then follow
[docs/VERIFY.md](../VERIFY.md).

The APK certificate fingerprint is the one published with this release.
The Firefox XPI is signed by AMO.

## Known limitations

- No independent security audit.
- Android passkey provider is build-verified, not hardware-verified.
- WebAuthn PRF was not tested on hardware.
- The test relying party for passkeys is client-only.
- Travel Mode is not a forensic control.
- Firefox tokens and passkey metadata use `browser.storage.local`.
- Emergency shares are base64 recovery shares, not contact-encrypted.
- No Firefox autofill yet.

## Install

- Android: install the signed APK from this release.
- Firefox: install the signed XPI from this release; updates are managed by the
  AMO unlisted channel.

## Reporting

Use GitHub private vulnerability reporting for security issues. Do not include
real credentials.
